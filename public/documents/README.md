# Aevoryn Company Documents Directory (/public/documents/)

This directory holds the official public PDF documents displayed on the `/documents` page of the website.

## Required Documents (Files to be supplied by Owner):

1. **`aevoryn-cr-7054401679.pdf`**
   - Official Commercial Registration Certificate (CR: 7054401679) issued by the Ministry of Commerce.

2. **`aevoryn-aramco-vendor-10120422.pdf`**
   - Official Saudi Aramco e-Marketplace vendor confirmation letter (Vendor Code: 10120422, E-Ref: 0019448).

3. **`aevoryn-iso-9001-vc23018822.pdf`**
   - ISO 9001:2015 Quality Management System Certificate (VC23018822) issued by Vatsin Certification.

4. **`aevoryn-iso-14001-vc23022982.pdf`**
   - ISO 14001:2015 Environmental Management System Certificate (VC23022982) issued by Vatsin Certification.

5. **`aevoryn-iso-45001-vc23032689.pdf`**
   - ISO 45001:2018 Occupational Health & Safety Certificate (VC23032689) issued by Vatsin Certification.

6. **`aevoryn-national-address.pdf`**
   - SPL National Address registration certificate for Riyadh HQ and Baish/Jizan support base.

Place the actual scanned PDF files with these exact filenames into this folder to enable direct client downloads.
